## Keep the profile current

Use [omg-software.org](https://omg-software.org/) as the reference for the brand and tone. The banner uses charcoal `#151616`, orange `#ff8954`, and warm white `#efeee8`. Keep essential information in Markdown so it remains readable on small screens and without images. GitHub controls the page layout and colours outside the banner.

Check project descriptions and readiness against each project's current README before changing the profile. Update the checked date when you review those summaries. State known limits and avoid unsupported security or production-readiness claims.

Preview both READMEs and the banner before merging. Keep image paths relative to each README. The banner is a self-contained SVG with no scripts, external fonts, or remote image dependencies.
